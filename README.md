# IT-Аптечка v4.4 🛠️

Мощный, компактный и полностью автономный инструмент для автоматизации обслуживания, чистки и ремонта операционных систем Windows. Всё упаковано в один удобный скрипт для работы с сервисных флешек.

## 🚀 Что нового в v4.4:
* **Исправлен Мод 15:** Полностью переработан и оживлен запуск системной утилиты диагностики оперативной памяти (`mdsched.exe`).
* **Умное завершение работы:** В Мод 16 добавлено вежливое графическое прощание с пользователем и аккуратный выход из консоли с задержкой.
* Скрипт очищен от лишних именных приветствий и стал полностью универсальным.

## 📜 История прошлых версий (v4.3):
* Auto-UAC: Автоматический запрос прав администратора при старте.
* Полная поддержка UTF-8: Идеальное отображение кириллицы в консоли без кракозябр.
* Ремонт обновлений: Жесткий сброс и перезапуск зависших системных служб через `taskkill /f`.
* Безопасная очистка Temp: Эффективное удаление мусора с помощью быстрого и надежного механизма `robocopy`.

## ⚠️ ВАЖНОЕ ТРЕБОВАНИЕ
Скрипт вносит глубокие изменения в системные настройки. Запуск строго **от имени Администратора** (Правой кнопкой мыши -> Запуск от имени администратора).
