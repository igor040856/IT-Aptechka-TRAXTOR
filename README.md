# IT-Аптечка v4.3

Мощный, компактный и полностью автономный инструмент для автоматизации обслуживания, чистки и ремонта операционных систем Windows. Всё упаковано в один удобный скрипт для работы с сервисных флешек.

## 🛠 Что нового в v4.3:
* **Auto-UAC:** Автоматический запрос прав администратора при старте.
* **Полная поддержка UTF-8:** Идеальное отображение кириллицы в консоли без кракозябр.
* **Ремонт обновлений:** Жесткий сброс и перезапуск зависших системных служб через taskkill /f.
* **Безопасная очистка Temp:** Эффективное удаление мусора с помощью быстрого и надежного механизма robocopy.

## 📂 Структура проекта:
Папка **Tools**:
* `README.md` — Инструкция и описание проекта.
* `IT-Аптечка v4.3.bat` — Главный и единственный исполняемый файл.

## 🚀 Инструкция по запуску:
1. Скопируйте папку **Tools** на вашу флешку.
2. Запустите файл **IT-Аптечка v4.3.bat**. Скрипт сам запросит повышенные привилегии благодаря встроенному Auto-UAC.
3. Выберите нужный пункт в появившемся текстовом меню консоли.
