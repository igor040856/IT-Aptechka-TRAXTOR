IT-Аптечка v4.3Мощный, компактный и полностью автономный инструмент для автоматизации обслуживания, чистки и ремонта операционных систем Windows. 
Всё упаковано в один удобный скрипт для работы с сервисных флешек.

Что нового в v4.3Auto-UAC: 
 Автоматический запрос прав администратора при старте.
Полная поддержка UTF-8: 
 Идеальное отображение кириллицы в консоли без кракозябр.
Ремонт обновлений:
 Жесткий сброс и перезапуск зависших системных служб через taskkill /f.  
Безопасная очистка Temp: 
 Эффективное удаление мусора с помощью быстрого и надежного механизма robocopy. 
Структура проектаПапка Tools: 
 README.md (Инструкция и описание проекта)IT-Аптечка v4.3.bat (Главный и единственный исполняемый файл)
Инструкция по запуску:
 Скопируйте папку Tools на вашу флешку. Запустите файл IT-Аптечка v4.3.bat. Скрипт сам запросит повышенные привилегии благодаря встроенному Auto-UAC. 
Выберите нужный пункт в появившемся текстовом меню консоли.
